# Cathy’s Interactive Learning Works

本儲存庫收錄凱西老師製作的互動教學作品，依教學內容分為研究誠信、佛學導讀、生命觀照及資料視覺化四類。

## 作品總覽

| 分類 | 作品 | 內容簡述 |

| 研究誠信 | [研究誠信 AI 小助理](research-integrity/) | 連結互動型 AI bot，協助理解臺灣研究誠信守則與誠信原則。 |
| 研究誠信 | [研究者的誠信之路](research-integrity/integrity-road.html) | 以研究旅程呈現誠實、尊重、嚴謹、課責與透明。 |
| 研究誠信 | [隱私權政策](research-integrity/privacy.html) | 說明資料處理、使用目的、第三方平台與使用者權益。 |

| 生命觀照 | [人生的三重風景](life-reflection/mountain-three-stages.html) | 呈現從執著、鬆動到自在的三階段生命轉折。 |
